# 03 声卡（Realtek ALC897）

## Sequoia 及以前

开启 AppleALC，`layout-id = 77`。耳机孔对应「内建输出」。HDMI 输出在 macOS 下本来就不能调音量，用显示器按键调。

## Tahoe 26

Tahoe 移除了 AppleHDA，单靠 AppleALC 不再出声。需要 [SimpleHDA](https://github.com/laobamac/SimpleHDA) 把 AppleHDA 装回来：

- 加载顺序：**Lilu → AppleALC → SimpleHDA**。SimpleHDA 只负责恢复 AppleHDA，**AppleALC 仍然必须加载**。
- SimpleHDA 设 `MinKernel = 25.0.0`（只在 Tahoe 加载）。
- SimpleHDA 1.0.0 需要启动参数 `keepsyms=1`，并打开 `Kernel → Quirks → DisableLinkeditJettison`。
- 踩坑：升级前曾把 AppleALC 的 `MaxKernel` 设成 24.99.99，导致 Tahoe 下 AppleALC 不加载、没声音。应该留空。

结果：出现「内建输出」「内建输入」。
