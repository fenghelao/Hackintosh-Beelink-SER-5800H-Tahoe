## 版本选择的经验

1. **恢复环境的版本 ≠ 最终安装的版本**。联网恢复会下载 Apple 当前推送的版本。恢复能进界面，只能说明恢复环境那个内核能跑。想装特定小版本，要用完整安装包（InstallAssistant）。
2. Sonoma 14.8.9 的恢复和安装是同一内核，适合作为"先装上再说"的起点。
3. **升级到 Tahoe 要锁定 26.7.2**：NootedRed pre‑release.15 的 Tahoe 参考数据就是按 26.7.2（25G332）生成的，驱动作者的开发机也是 5800H + 26.7.2。更新的小版本可能让显卡修复全部失效。
   ```bash
   softwareupdate --list-full-installers
   softwareupdate --fetch-full-installer --full-installer-version 26.7.2
   ```
   改过 SIP 后，系统设置里不会再出现升级入口，只能用完整安装包。
4. macOS 26 是 Intel / 黑苹果能装的最后一个大版本，macOS 27 只支持 Apple 芯片。升级不可逆，降级只能抹盘重装。

## 安装步骤（概要）

1. U 盘：FAT32，放 `EFI/` 和 `com.apple.recovery.boot/`（用 [macrecovery](https://github.com/acidanthera/OpenCorePkg/tree/master/Utilities/macrecovery) 下载）。卷名用英文，中文卷名在 OpenCore 菜单里会显示成下划线。
2. BIOS：开机按 **F7** 选 U 盘的 **UEFI** 启动项。Secure Boot 是关闭的；其他 BIOS 设置保持默认即可，不需要照搬独显机器教程里的 ReBAR、Above 4G 等设置。
3. 磁盘工具 →「显示所有设备」→ 选**最顶层的物理盘**抹掉：APFS、GUID 分区图，卷名用英文 `macOS`。
4. 安装中会自动重启多次。可以把 OpenCore 设成 5 秒后自动启动 macOS 指定的那一项，就不用每次都手动选。
5. 金士顿无缓存盘在 macOS 下写入慢：安装时每一段进度条至少等 30 分钟再判断是否卡死；开机时 `SetApfsTrimTimeout` 设成 0 可以跳过长时间的 trim。系统装好后再改回 -1，打开 TRIM。
6. 装好后：把 EFI 复制到内置盘的 EFI 分区；OpenCore 换回 RELEASE 版；去掉 `-v keepsyms=1 debug=0x100` 等调试参数（Tahoe 上 SimpleHDA 需要保留 `keepsyms=1`）。

## 卡住时怎么收集日志

在恢复环境的终端里，把内置盘上的 `/var/log/install.log`、统一日志、崩溃报告、`nvram -xp` 复制到 U 盘。OpenCore 开启文件日志后，每次启动会在 U 盘根目录留一份 `opencore-*.txt`；内核崩溃会留 `panic-*.txt`。
